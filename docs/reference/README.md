# 原始人格资料（参考用）

这里放的是**原始素材**，供改人格时查阅。日常使用不需要读它们。

| 文件 | 内容 | 什么时候看 |
|------|------|------------|
| [`ELY_PERSONA.md`](ELY_PERSONA.md) | 精调人格包 v1.0：说话规则、场景模式、经典台词、对话示例 | 想微调语气和长度时 |
| [`ELY_ANALYSIS.md`](ELY_ANALYSIS.md) | 人格模型深度分析：存在论核心、性格三层结构、语言指纹、关系网、扮演指南 | 想理解「为什么这么说话」时 |
| [`elysia-personality.md`](elysia-personality.md) | 价值观体系、动机层次、核心矛盾、情绪触发模式、语气量化 | 想加场景或改情绪反应时 |
| [`elysia-profile.md`](elysia-profile.md) | 角色档案：身份、称号、外观、核心事迹 | 需要设定细节时 |
| [`elysia-lines.md`](elysia-lines.md) | 台词样本库（252 条量级），按场景分类 | 想写彩蛋台词、或给语音准备素材时 |

## 和 `persona/` 的关系

```
docs/reference/   → 原始素材（长、细、供参考）
persona/          → 提炼后可直接喂给模型的提示词
```

`persona/` 是从这些素材里**提炼 + 重写**的，不是原文照搬：

- 删掉了面向「剧本分析」的内容（如关系网、剧情考据）；
- 把「傲娇嘴硬」一类不适配爱莉的表述换成「俏皮化解」；
- 补了红线（不说脏话、不糊弄）与正反示例；
- 加了 AstrBot 侧的仿真协议（原文没有）。

改人格时建议：**先改 `persona/`，再回这里查依据**，不要直接把 reference 里的长文塞进提示词——那是分析文档，不是指令。
