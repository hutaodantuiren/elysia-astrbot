# 快速开始（15 分钟）

> 目标：在 QQ 群里收到第一条爱莉的声音。
> 前置：已装好 [AstrBot](https://github.com/AstrBotDevs/AstrBot) 并能正常收发文字消息。

---

## 第 0 步：确认你没有漏掉前置

| 检查项 | 怎么确认 |
|--------|----------|
| AstrBot 能收发文字 | 群里发 `ping`，机器人有回应 |
| 有 Python 3.10+ | `python --version` |
| 有 ffmpeg | `ffmpeg -version`（AstrBot 转语音格式要用） |
| 磁盘剩 8GB+ | 声音克隆模型约 3GB，加上依赖和输出 |

---

## 第 1 步：装声音克隆引擎

按 [02-语音引擎部署.md](02-语音引擎部署.md) 装 CosyVoice2，装完你能用官方 webui 听到「你好呀，我是爱莉希雅♪」。

**这一步不能跳。** 没有引擎，插件只能返回错误提示。

装好后确认引擎对外提供 HTTP 接口，例如：

```bash
curl -X POST http://127.0.0.1:9880/api/tts \
  -H "Content-Type: application/json" \
  -d '{"text":"你好呀，我是爱莉希雅","ref":"g-05.wav"}' \
  --output test.wav
ffplay test.wav     # 能听到爱莉的声音就成功
```

如果引擎还没暴露这样的接口，用 [config/adapter-cosyvoice.py](../config/adapter-cosyvoice.py) 包一层（见 [03-AstrBot配置.md](03-AstrBot配置.md#接自己的-tts)）。

---

## 第 2 步：放好参照音

```bash
# Linux / macOS
bash scripts/install-clips.sh /你的/CosyVoice/refs/elysia
```

```powershell
# Windows PowerShell
powershell -ExecutionPolicy Bypass -File scripts/install-clips.ps1 -Target "D:\AI\CosyVoice\refs\elysia"
```

脚本会把 `voice-clips/g-01.wav` ~ `g-20.wav` 复制过去，并打印清单。

> 如果你的引擎从别的目录读参照音，改 `-Target` / 第一个参数即可；插件的 `api_url` 那边只要服务端能找到 `ref` 文件名就行。

---

## 第 3 步：装插件

```bash
# 把插件目录整个复制进 AstrBot
cp -r plugins/astrbot_plugin_elysia_voice <AstrBot>/data/plugins/
```

Windows 直接拖文件夹到 `<AstrBot>\data\plugins\`。

然后**重启 AstrBot**，WebUI → 插件管理，应该能看到「爱莉希雅语音」。

---

## 第 4 步：配插件

WebUI 里点开插件配置，最少改两项：

| 配置项 | 填什么 |
|--------|--------|
| `api_url` | 你的 TTS 接口，如 `http://127.0.0.1:9880/api/tts` |
| `default_ref` | 默认参照音，如 `g-05.wav` |

保存后，在群里发：

```
/爱莉语音状态
```

应该回一条状态信息（说明插件加载成功、地址正确）。

---

## 第 5 步：贴人格

WebUI → 配置 → **人格**（有的版本叫「系统提示词 / Persona」）：

1. 新建一个人格，名字随便（例如 `elysia`）。
2. 打开 [`persona/elysia-all-in-one.md`](../persona/elysia-all-in-one.md)，**整份复制粘贴**。
3. 设为默认人格（或在会话里切换）。

> 想干净一点就分两份：人格字段贴 `elysia-persona.md`，工具/指令说明贴 `elysia-simulation.md`。

---

## 第 6 步：试一句

```
/爱莉说 你好呀，我是爱莉希雅，今天也请多指教啦♪
```

几秒后群里应该出现一条**语音**。

如果只是文字回复「……帮不了」，说明 `api_url` 不通，去 [03-AstrBot配置.md](03-AstrBot配置.md#排错) 对着排错表看。

---

## 下一步

- 调语气 → 换 `default_ref`，或用 `emotion_map` 做情绪路由
- 调触发词 → 改 `main.py` 里的 `@filter.command("...")`
- 想全自动语音 → 见 [03-AstrBot配置.md](03-AstrBot配置.md#自动口播可选)
- 想换角色 → 保留插件，只换人格和参照音
