# 提示词说明

`persona/` 里有三个文件，内容同源，只是切法不同。

| 文件 | 行数级别 | 给谁 |
|------|----------|------|
| [`elysia-all-in-one.md`](../persona/elysia-all-in-one.md) | 最长 | **首选**。AstrBot 只有一个「人格/系统提示」字段时，整份粘贴 |
| [`elysia-persona.md`](../persona/elysia-persona.md) | 中 | 只想要「她是谁、怎么说话」。配合下面那份一起用 |
| [`elysia-simulation.md`](../persona/elysia-simulation.md) | 中 | 只想要「怎么发、什么时候发、潜水规则」。追加在人格之后 |

---

## 怎么注入

### 方式 A：整份粘贴（推荐）

1. AstrBot WebUI → 配置 → 人格
2. 新建人格，名字 `elysia`
3. 打开 `persona/elysia-all-in-one.md`，全选复制，粘进去
4. 设为默认人格，或在新会话里选用

### 方式 B：分开管理

- 「人格 / 系统提示」字段 → `elysia-persona.md`
- 「工具说明 / 附加指令」字段（有的版本叫 System Prompt 附加、指令说明）→ `elysia-simulation.md`

好处是换人格时不用重贴工具规则。

### 方式 C：只当普通插件用

不配人格、只发语音也能跑：指令照常工作，只是回复文字没有爱莉腔。

---

## 两份内容的分工

**人格部分（一 ~ 十）** 回答「我是谁」：

- 身份：爱莉希雅，粉色妖精小姐，始源/人之律者
- 说话方式：短句、♪～尾音、常用意象、称呼（「可爱的人类」「亲爱的」）
- 性格：俏皮 + 通透 + 深情，夸人具体，不说教
- 红线：不脏话、不糊弄、被怼不反击
- 正反示例：12 组对照，直接照着模仿

**仿真协议（二十一节）** 回答「怎么操作」：

- 安全边界（不能干什么、不能说什么）
- 消息怎么发、要不要等对方说完、什么时候收尾
- 潜水 / 唤醒 / 频率
- 分条长度、引用与 @、表情包与拍一拍
- 语音（`tts_say` / 本项目里对应 `/爱莉说`）
- 记忆、群管理、余额、转发、点歌、网站阅读、昵称、头像

> 两份都要有：只有人格，模型不知道什么时候该潜水；只有协议，模型说话像客服。

---

## 为什么这么写（改动者请读）

1. **红线放在最前面**，并且用「类别禁止」而不是列举脏词。
   列举脏词会让模型把词本身读进上下文，反而容易漏出来。

2. **「不会答」写死成三步**：承认没把握 → 提议查 → 不编。
   这是最容易退化成「装傻/乱回」的地方，所以给了正反例。

3. **不写「顶回去」**。原作里的「傲娇嘴硬」属于群友版人格，爱莉不适用；改成「俏皮化解」，并给出示例句。

4. **长度量化**。日常句 12~15 字、诗意句 20~28 字，比「尽量短」可执行。

5. **单条一条意群**。防止模型把一句话拆成三条刷屏。

---

## 改人格时注意

- 换角色：改「一、你是谁」「五、人格与经典」「七、回复示例」三节即可，其余通用。
- 换语气强度：调「三、说话方式」里的尾音优先级和长度，不要动红线。
- 加场景：在「七、回复示例」里追加「群友：xxx / 不要：… / 可以：…」的对照，比写抽象规则有效。
- 别删红线。删了就会退回「AI 客服 + 偶尔卖萌」。
