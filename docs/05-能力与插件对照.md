# 能力与插件对照

> 一句话结论：**本仓库只自带「语音」一个插件**。人格协议里写的表情包、拍一拍、点歌、改昵称、记忆、群管、网页阅读……都需要**另外装插件**，或根本做不到。

不看清这张表，最容易出的问题是：人格写着「可以发表情包」「可以点歌」，模型就会照做，然后在群里假装发了——实际上什么都没发出去。

---

## 一、总览

| 协议章节 | 能力 | 怎么实现 | 具体插件 / 位置 |
|----------|------|----------|------------------|
| 十六 | **发语音** | ✅ 本仓库自带 | [`plugins/astrbot_plugin_elysia_voice`](../plugins/astrbot_plugin_elysia_voice/) |
| 九 | **发表情包 / 斗图** | 🔌 需插件 | [`ctrlkk/astrbot_plugin_meme_manager_lite`](https://github.com/ctrlkk/astrbot_plugin_meme_manager_lite)、[`QingchenWait/astrbot_plugin_smart_imagechat_hub`](https://github.com/QingchenWait/astrbot_plugin_smart_imagechat_hub) |
| 九 | **拍一拍** | 🔌 需插件（且适配器要支持） | [`kazamisama/astrbot_plugin_litepoke`](https://github.com/kazamisama/astrbot_plugin_litepoke)、[`Zhalslar/astrbot_plugin_pokepro`](https://github.com/Zhalslar/astrbot_plugin_pokepro) |
| 九 | **看懂群友发的图** | ✅ 原生 | 把模型换成多模态（如 Qwen-VL / GPT-4o / GLM-4V），AstrBot 会把图片一起送进上下文 |
| 十一 | **长期记忆** | 🔌 需插件 | [`Bluezeamer/astrbot_plugin_memory`](https://github.com/Bluezeamer/astrbot_plugin_memory)、[`AlanBacker/astrbot_plugin_memory_beyond`](https://github.com/AlanBacker/astrbot_plugin_memory_beyond) |
| 十二 | **禁言 / 撤回 / 踢人 / 改群名片** | 🔌 需插件 | [`Zhalslar/astrbot_plugin_QQAdmin`](https://github.com/Zhalslar/astrbot_plugin_QQAdmin)（仅 aiocqhttp，且机器人须是管理员） |
| 十八 | **点歌** | 🔌 需插件 | [`Zhalslar/astrbot_plugin_music`](https://github.com/Zhalslar/astrbot_plugin_music)、[`NachoCrazy/netease-music-astrbot-plugin`](https://github.com/NachoCrazy/netease-music-astrbot-plugin) |
| 十九 | **网页搜索 / 读网页** | 🔌 需配置 | AstrBot 内置联网搜索（[文档](https://docs.astrbot.app/use/websearch/deepseek.html)）；或 [`piexian/astrbot_plugin_grok_web_search`](https://github.com/piexian/astrbot_plugin_grok_web_search) |
| 二十 / 二十一 | **改昵称 / 换头像** | 🔌 需插件 | [`Zhalslar/astrbot_plugin_qqprofile`](https://github.com/Zhalslar/astrbot_plugin_qqprofile)（仅 aiocqhttp） |
| 十三 | **查余额** | ❌ 做不到 | 这是原来 DSH 桥接的特有能力，AstrBot 没有对应接口 |
| 十五 | **展开合并转发** | ⚠️ 看适配器 | aiocqhttp 支持部分转发消息；其它协议可能完全收不到 |
| 八 | **引用回复 / @ 人** | ✅ 原生 | aiocqhttp 适配器支持引用；@ 需要平台允许 |
| 三 / 四 | **概率唤醒 / 潜水** | ⚠️ 部分 | AstrBot 有「主动回复」与概率设置；`speakerIds` 这类精细规则没有 |
| 五 / 六 / 七 | 参与节奏、反 AI 味、分条 | ✅ 纯提示词 | 不需要插件，靠人格约束 |

> 🔌 = 要装第三方插件；✅ = 开箱可用；⚠️ = 取决于适配器/配置；❌ = 建议直接删掉该节。

## 二、装插件前先想清楚

| 插件 | 装上之后的风险 |
|------|----------------|
| 表情包 | 很容易刷屏；建议限制频率（如每 5 轮最多 1 张），并关闭「自动配图」 |
| 拍一拍 | 有的插件会持续拍人，很扰民；确认有冷却 |
| 群管 | 机器人一旦是管理员，误禁言/误撤回的代价很高；建议只给自己和熟人开 |
| 记忆 | 会长期保存群友发言，涉及隐私；确认存储位置与清理方式 |
| 点歌 | 版权与带宽；免费源经常失效 |
| 网页搜索 | 消耗额度；搜到的内容不可信，别直接复述 |

## 三、没装插件时，怎么让人格闭嘴

有两种做法，选一种即可。

### 做法 A：删掉对应小节（推荐）

打开 [`persona/elysia-simulation.md`](../persona/elysia-simulation.md)，把没装插件的章节整节删掉。比如只保留：一（安全）、二（发消息）、三（收尾）、七（分条）、八（引用）、十四（不汇报）、十六（语音）。

删掉比留着有效：模型看不到「可以点歌」，就不会点歌。

### 做法 B：在人格开头加一段能力声明

如果你的 AstrBot 会把工具列表注入上下文，可以不改协议，只在人格最前面加：

```
## 能力声明
你当前只能做这些事：收发文字、发语音（/爱莉说）。
下面协议里提到的表情包、拍一拍、点歌、改昵称、换头像、记忆、群管、查余额，
如果你在工具列表里看不到对应工具，就是没有。
没有的能力要直接说"这个爱莉还不会呢"，绝不允许假装已经做了。
```

这段比任何技巧都管用——它把「假装」明确写成了违规。

## 四、每装一个插件，记得同步改三处

1. **人格协议**：把对应小节从「建议」改成「可以」，并写上真实指令名。
2. **README 的插件表**（下面那张），让后来的人知道依赖。
3. **启动脚本/文档**：记录版本，插件更新常改接口。
