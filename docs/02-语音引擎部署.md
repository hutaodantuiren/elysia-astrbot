# 语音引擎部署（CosyVoice2 / GPT-SoVITS）

> 引擎只装一次，之后所有角色共用。本页给两条路线，**先走 A**。

| 路线 | 适合 | 难度 | 克隆质量 |
|------|------|------|----------|
| A. CosyVoice2（零样本） | 大部分人 | 中 | 好，开箱即用 |
| B. GPT-SoVITS（few-shot / 微调） | 追求更像 | 高 | 最好，但要训练 |

---

## 路线 A：CosyVoice2（推荐）

### A1. 环境

- Windows / Linux / macOS
- Python 3.10（64 位）
- `ffmpeg` 可用
- 磁盘 ≥ 8GB
- 有 NVIDIA 显卡更快；没有也能跑 CPU（慢）

### A2. 下模型（约 3GB）

```bash
pip install modelscope
modelscope download --model iic/CosyVoice2-0.5B --local_dir ./models/cosyvoice2
```

最终目录里应有 `cosyvoice2.yaml`、`llm.pt`、`flow.pt` 等文件。

国内网络用 ModelScope 比 HuggingFace 稳；断点续传就重复执行上面的命令。

### A3. 装代码

```bash
git clone https://github.com/FunAudioLLM/CosyVoice.git
cd CosyVoice
pip install -r requirements.txt
```

### A4. 放参照音

```bash
bash <this-repo>/scripts/install-clips.sh /你的/CosyVoice/refs/elysia
```

或手动把 `voice-clips/*.wav` 复制过去。

> **参照音是什么**：一段 3~15 秒、干净无背景音乐的真人语音。引擎「听」它，然后模仿这个音色念新文本。本仓库 20 条就是 20 种语气样本。

### A5. 验证

```bash
python webui.py --port 9880
```

浏览器开 `http://127.0.0.1:9880`，「零样本 / zero-shot」栏：

- 参照音频：`g-05.wav`
- 合成文本：`你好呀，我是爱莉希雅♪`

能听到声音 = 引擎 OK。

### A6. 暴露 HTTP 接口给 AstrBot

如果你用的 CosyVoice 版本自带 API，直接用它；否则用本仓库的适配器：

```bash
pip install fastapi uvicorn
python <this-repo>/config/adapter-cosyvoice.py --port 9880
```

适配器把引擎包成统一契约（见 [config/api-contract.md](../config/api-contract.md)）：

```
POST /api/tts   {"text": "...", "ref": "g-05.wav"}   →   audio/wav
```

## 路线 B：GPT-SoVITS

适合「CosyVoice 听着不够像」的情况。代价是要准备数据、跑训练。

1. 部署 GPT-SoVITS（官方整合包最省事）。
2. 用 `voice-clips/` 的 20 条做**参考音频**：
   - 先试 `api_v2` 的 zero-shot（给 `ref_audio_path` + `prompt_text`），不训练也能用；
   - 想更像再做微调：挑 1~3 分钟干净语音，跑一次 SoVITS 训练。
3. 启动它的 API，得到类似 `http://127.0.0.1:9880/tts` 的端点。
4. 用 `config/adapter-gpt-sovits.py` 把它翻译成本仓库的契约，或直接改插件 `api_url` + 请求字段映射。

> 注意：GPT-SoVITS 的 zero-shot 需要**参照音的文本**。`voice-clips` 里没有逐条转写，所以要么听写一句，要么用它的 `inference` 接口先做一遍 ASR。

## 常见报错

| 报错 | 原因 | 处理 |
|------|------|------|
| `No module named 'cosyvoice'` | 没装 requirements | 回到 A3 |
| 下载卡住 / 超时 | 走了 HuggingFace | 用 ModelScope 命令 |
| `ffmpeg not found` | 没装 ffmpeg | 装好并加入 PATH |
| 爆显存 | 模型太大 | 换 `fp16`、减小 `max_token_num`，或 CPU 推理 |
| 合成很慢（>30s） | CPU 推理 | 正常，短文本可接受；或换 GPU |
| 输出的音频有杂音 | 参照音不干净 | 换一条更干净的 `g-0X.wav` |

## 关于模型与版权的提醒

- CosyVoice 模型许可见其仓库（Apache-2.0 衍生），商用前自行确认。
- **声线克隆的道德边界**：本仓库的 20 条参照音来自游戏公开配音，仅限个人同人使用。不要用它冒充真人、生成虚假信息或商用。
