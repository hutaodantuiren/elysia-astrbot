> 想做得准，自己听一遍，把归类写进 [`config/emotion-map.json`](../config/emotion-map.json)。

## 怎么用

1. 全部复制到 TTS 引擎的参照音目录（`scripts/install-clips.*` 可一键完成）。
2. 插件里 `default_ref` 填 `g-05.wav`，需要时用 `/爱莉说 [g-11] …` 临时切换。
3. 参照音越短越干净，克隆越稳；超过 20 秒的样本反而容易带进杂音。

## 挑选建议

- **日常聊天**：`g-05`（元气）或 `g-02`（短句）
- **认真、陪伴、安慰**：`g-11`（深情）或 `g-01`（温柔长句）
- **念长文 / 台词**：`g-03`、`g-16`（长段样本更稳）
